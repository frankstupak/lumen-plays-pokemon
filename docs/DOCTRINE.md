# Doctrine (binding on all agents building this project)
2026-08-02, set by Frank.

## The point we are proving
An independent operator with a self-built fleet can out-engineer the labs' showcases. Unpaved road only.

## Originality rule
- ZERO borrowed harness code. No forks, no ports, no adapted scaffolds, no copied prompt kits. Public runs are studied for FAILURE INTELLIGENCE only (where they broke, how long, why) — never for design.
- Everything differentiating is scratch-built and already is: symbol parser, banked ROM reader, map/collision model, A* navigator, memory/prompt architecture, brain router, event bus, stream server, kiosk. Keep it that way.
- Raw materials (Node, TS, an emulator core, ws) are materials, not designs. The intelligence architecture is 100% ours.
- Optional endgame flex on the horizon: a scratch-built Lumen GB core to replace serverboy. Not scheduled; noted as the final word if we ever want it.

## Elegance standards
- One coherent TS codebase; small files, single responsibilities; no framework sprawl.
- ZERO hardcoded game data: every address symbol-derived, every map fact read from RAM/ROM at runtime. If it can be derived, it must be derived.
- Every claim grounded in RAM truth; every run replayable from its event stream alone.
- Self-healing over hand-holding: the executor learns and replans; hints in prompts are a defeat.
- Deterministic tools carry mechanics; the model spends tokens only on judgment.

## More functional than anyone else — concrete superiority targets
1. RAM-first perception (others were vision-bottlenecked; we are not).
2. Warp-graph world model handed to the model (nobody has this; it is the Silph Co killer).
3. Append-only, checkpoint-coupled memory — notes survive rollbacks; the note-deletion death is structurally impossible here.
4. Bi-temporal run memory (Memory V2 pattern applied to gameplay: what was believed vs when).
5. Live reasoning kiosk streaming real chain-of-thought, not post-hoc summaries.
6. Multi-game concurrency on one harness; then $0 local-inference runs on our own silicon (Hapi).
7. Every run is a benchmark artifact: steps/badge, tokens/badge, model-vs-model on identical checkpoints.
